# Notes
Chapter 4 was a deep dive into syntax in functions in Haskell, how to use pattern matching, guards, and case expressions.
Patterns are a way of making sure a value conforms to some form, for example we could check if a variable is between 5 and 10, for instance, and then performing some action. You can also create multiple patterns that values have to 'fall through' before reaching the final 'catch-all' pattern.
Guards test some property of a value, and return true or false, similar to if-else statements in imperative programs but are more readable.
