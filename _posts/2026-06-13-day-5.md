# What I did today
Chapter 8 was about making your own Types and Typeclasses.

This was not too new to me given my experience with Typescript, all the different types that exist (int, Bool, String and so on), and 
defining your own types. Typescript takes types very seriously (well obviously, it's in the name) and will scream at you for the tiniest mistake, 
Haskell seems relatively chill in comparison.

Typeclasses also exist, not to be confused with Classes in imperative languages. Typeclasses define behaviours. The `Eq` typeclass 
for example defines behaviours for stuff that can be equated, like integers (`3 == 3`). There are many others, like `Ord` for types 
that follow an order, `Bounded` for types that have a specified upper and lower bound, and so on.

The chapter covers a few more things on types and typeclasses which I'll become more familiar with the more Haskell I write.
