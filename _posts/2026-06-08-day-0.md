## Notes
- General background: Computers only understand binary (1s and 0s), and interacting with them in this manner got complex real fast and so programming languages were created. A way to give instructions to the computer with syntax similar to human language, making them human readable.
- Today, there are all sorts of programming languages serving similar or different purposes. Overtime the concept of paradigms began, simply meanining the different ways a problem can be solved using these programming languages. There are many different [programming paradigms](https://en.wikipedia.org/wiki/Programming_paradigm)
= *Imperative* and *Object Oriented* Programming are the most common paradigms, however to understand the inner workings of programming languages, one needs to be familiar with *Functional* programming, hence Haskell
- Haskell is an advanced, statically typed, purely functional programming language.
