A few fun facts I can remember off the top of my head:
1. Almost everything is a function: Including your standard operators (+, -, *, =, == etc). These are all functions, meaning they take input and
   return output.
3. Functions can only take one parameter: This one is weird. In every other language I know functions take 0 or more parameters, for example
 ```max(x, y)```. But apparently in Haskell, functions can only take a single parameter. While you still write something like ```max x y```,
 it actually translates to ```(max x) y```. ```max x``` takes `x` as a parameter and returns a function that then takes y as its parameter
and returns the result. This process is called `currying`. This is probably not a great explanation, I'm currently trying to fully wrap my head around it too.
4. Also you can implement quick-sort in like 5 lines. For the uninitiated, quick-sort is a really efficient sorting algorithm, but its fairly complex (at least for beginners),
 and even in a language with as simple syntax as python, most implementations still take upwards of 10 lines.
